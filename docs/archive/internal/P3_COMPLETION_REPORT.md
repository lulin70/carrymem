### P3-2: CORS匹配加固 ✅

**优先级**: 🟢 低

**修复方案**:

**修改文件**: `src/memory_classification_engine/integration/layer2_mcp/http_server.py`

4. ✅ 详细的日志记录

**效果**:
- ✅ 防止无效的origin通过验证
- ✅ 防止端口溢出攻击
- ✅ 更清晰的错误日志

### P3-3: HTTP错误响应脱敏 ✅

**优先级**: 🟢 低  
**影响**: 安全性（信息泄露）  
**工作量**: 45分钟

**问题描述**:  
HTTP 500错误响应可能泄露敏感信息（如文件路径、堆栈跟踪）。

**修复方案**:  
在生产环境中返回通用错误信息，只在调试模式下显示详细错误。

**修改文件**: `src/memory_classification_engine/integration/layer2_mcp/http_server.py`

**改进前**:
```python
except Exception as e:
    await self._send_response(writer, 500, {"error": str(e)}, "")
    # ❌ 可能泄露堆栈信息
```

**改进后**:
```python
except Exception as e:
    logger.error(f"Request handling error: {e}", exc_info=True)
    error_msg = "Internal server error"
    if os.environ.get("CARRYMEM_DEBUG") == "1":
        error_msg = str(e)  # 仅在调试模式显示详情
    await self._send_response(writer, 500, {"error": error_msg}, "")
```

**效果**:
- ✅ 生产环境不泄露敏感信息
- ✅ 详细错误记录到日志（便于调试）
- ✅ 调试模式下仍可查看详细错误
- ✅ 符合安全最佳实践
