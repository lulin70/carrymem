## 一、项目初心回顾

### 原始愿景
> "让AI记住用户身份（偏好、决策、纠正），实现跨工具、跨模型的可移植记忆层"

### 核心目标
1. **自动分类**：AI自动识别7种记忆类型
2. **语义召回**：跨语言的智能记忆检索
3. **跨工具使用**：通过MCP在不同AI工具间共享
4. **数据自主**：本地存储，用户完全控制
5. **企业就绪**：Rule Engine支持团队协作
